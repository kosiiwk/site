# Furniro - E-Commerce Header Practice

The goal for today was to build a clean, pixel-perfect header component based on a Figma e-commerce design.

##  Status
*  **Current State:** Header navigation component completed.
*  **Links & Buttons:** Currently act as placeholders (`href="#"`).

##  Built With
* **HTML** (Semantic layout & BEM methodology)
* **CSS** (Flexbox, CSS Variables, and fluid `clamp()` sizing)
* **Figma** (Design source)

##  Features
* Fluid header navigation that scales smoothly across desktop and laptop viewports using CSS `clamp()`.
* Clean, non-overflowing layout on screens down to tablet sizes.
* Organized and scalable BEM class structure.
* Global CSS variables for easy theme customization.
